# Codexcript

Codexcript is a unique game where you play as a video game modder inside a simulated desktop environment. Your goal is to write code that modifies a fictional RPG game, unlocking new features, fixing bugs, and customizing gameplay to your liking.

## Features
- Immersive fake desktop interface with files, folders, and tools
- In-game code editor for writing and testing mods
- Challenging modding tasks and puzzles
- Simulated RPG game that responds to your code changes
- Discover secrets and hidden content by exploring and hacking the environment

## Technologies Used
- Unity (C#)
- Custom scripting system for mods
- Game logic and puzzles
