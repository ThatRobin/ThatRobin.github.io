# Extra Keybinds

Extra Keybinds is a Minecraft mod for the Origins mod that adds a variety of new keybinds, allowing you to create and use datapacks with more than just the default two keybinded powers. This greatly expands the possibilities for custom powers and gameplay!

## Features
- Adds 8 new keybinds to Origins, for a total of 10
- Lets datapack creators assign powers to more keys
- Works with all Minecraft versions and Origins versions after 1.17 (unless otherwise noted)
- Designed for compatibility with future versions

## Requirements
- Minecraft (any version, 1.17+ recommended)
- Origins mod
- Fabric Loader
- Fabric API

## Usage in Datapacks
Assign your powers to these keys in your datapack:

1. Primary: `key.origins.primary_active`
2. Secondary: `key.origins.secondary_active`
3. Ternary: `key.origins.ternary_active`
4. Quaternary: `key.origins.quaternary_active`
5. Quinary: `key.origins.quinary_active`
6. Senary: `key.origins.senary_active`
7. Septenary: `key.origins.septenary_active`
8. Octonary: `key.origins.octonary_active`
9. Nonary: `key.origins.nonary_active`
10. Denary: `key.origins.denary_active`

## Status
The mod should work with all future versions unless stated otherwise.
